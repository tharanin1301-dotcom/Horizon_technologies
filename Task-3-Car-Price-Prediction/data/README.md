# Dataset Information

This dataset was sourced publicly for the purpose of the Horizon TechX Internship (Task 3 - Car Price Prediction Using Regression).

> **IMPORTANT DISCLAIMER**: Horizon TechX did **NOT** provide this dataset. This dataset was independently procured from a reputable public machine learning repository to fulfill the task requirements.

## Dataset Details
- **Source Name**: UCI Machine Learning Repository
- **Dataset Name**: Automobile Data Set (1985)
- **URL**: [https://archive.ics.uci.edu/ml/datasets/automobile](https://archive.ics.uci.edu/ml/datasets/automobile)
- **Modifications**: The raw .data file was downloaded, and column headers were manually attached based on the official dataset documentation (.names file). Missing values represented by ? were explicitly converted to standard missing indicators (NaN) during import.

## Features List

The dataset includes the following columns:

1. **symboling**: Insurance risk rating (-3 to +3).
2. **normalized-losses**: Relative average loss payment per insured vehicle year.
3. **make**: Manufacturer (e.g., alfa-romero, audi, bmw).
4. **fuel-type**: Type of fuel (gas or diesel).
5. **aspiration**: Standard or turbo.
6. **num-of-doors**: Two or four.
7. **body-style**: E.g., sedan, hatchback.
8. **drive-wheels**: E.g., fwd, rwd.
9. **engine-location**: Front or rear.
10. **wheel-base**: Wheelbase of the car.
11. **length**: Length of the car.
12. **width**: Width of the car.
13. **height**: Height of the car.
14. **curb-weight**: Weight of the car without occupants or baggage.
15. **engine-type**: Type of engine (e.g., dohc, ohcv).
16. **num-of-cylinders**: Number of cylinders.
17. **engine-size**: Size of the engine.
18. **fuel-system**: Fuel system type (e.g., mpfi, 2bbl).
19. **bore**: Cylinder bore diameter.
20. **stroke**: Engine stroke length.
21. **compression-ratio**: Engine compression ratio.
22. **horsepower**: Engine horsepower.
23. **peak-rpm**: Engine peak RPM.
24. **city-mpg**: Fuel efficiency in city driving (miles per gallon).
25. **highway-mpg**: Fuel efficiency in highway driving.
26. **price** *(Target Variable)*: Selling price of the vehicle.
