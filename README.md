# Horizon Technologies Internship Projects

This repository contains the internship projects for the Horizon TechX internship program. It is structured to hold multiple machine‑learning tasks, each in its own folder.

## Repository Overview

- **Task-1-Iris-Flower-Classification** – Complete beginner‑friendly Iris classification project (implemented).
- **Task-2-Unemployment-Analysis** – Placeholder for unemployment data analysis (pending).
- **Task-3-Car-Price-Prediction** – Placeholder for car price prediction project (pending).

## General Setup Instructions

1. **Clone the repository** (once created on GitHub):
   ```bash
   git clone <repo‑url>
   cd Horizon-Technologies
   ```
2. **Create a virtual environment** (optional but recommended):
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # macOS/Linux
   source venv/bin/activate
   ```
3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
4. Navigate to the task folder you wish to run and follow the instructions in its `README.md`.
